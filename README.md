# Ótica Meni Becker — site público

Site institucional responsivo em HTML, CSS e JavaScript puro.

## Estrutura
- `index.html` — página completa
- `styles.css` — identidade visual e responsividade
- `script.js` — interações, filtros, formulário e acessibilidade
- `assets/logo.jpg` — logo fornecida

## Antes da publicação
1. Abra `script.js` e troque `WHATSAPP` pelo número comercial real no formato internacional, sem `+`, espaços ou símbolos.
2. Substitua endereço, horário e telefone no `index.html`.
3. Troque os blocos visuais demonstrativos da coleção pelas fotos reais dos produtos.
4. Substitua a galeria pelos registros reais da loja.
5. Revise a Política de Privacidade/LGPD com os dados reais da empresa.
6. Se quiser captar e-mails, conecte o formulário a um serviço/backend.

## GitHub Pages
1. Crie um repositório no GitHub, por exemplo `mb-optica-site`.
2. Envie todos os arquivos mantendo a estrutura de pastas.
3. Em Settings > Pages, selecione a branch `main` e a pasta `/root`.
4. Salve. O GitHub fornecerá o endereço público do site.

## Domínio próprio
Depois, um domínio como `www.mboptica.com.br` pode ser apontado para o GitHub Pages ou para uma hospedagem como Vercel.

## Observação
O site é deliberadamente independente do sistema interno MB.Óptica. Na próxima fase, o catálogo, estoque, agendamento e outros dados podem ser integrados ao sistema.
